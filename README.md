<center><p style="text-align: center;">With this mod, husks now have a chance to drop sand upon death. Since husks spawn in deserts, it only makes sense they'd have some sand clinging to them. This simple tweak opens the door for sand farms. And because this mod is configurable, you can tune it to your liking and make it balanced.&nbsp;</p>
<p style="text-align: center;"><img src="https://i.imgur.com/ESe7V8v.gif" /></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/huskssand.json</code> in your profile folder. If you're using Fabric and want to adjust the config values in-game, you'll need to install <a href="https://modrinth.com/mod/modmenu">Mod Menu</a>. Please note that any changes will require restarting Minecraft to take effect.</p>
<center>
<p style="text-align: center;"><b>min_rolls</b> - Sets the minimum number of sand blocks that can be dropped</p>
<p style="text-align: center;"><b>max_rolls</b> - Sets the maximum number of sand blocks that can be dropped</p>
</center>
